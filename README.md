# DevQuest 冒险者公会

把 DSH 里真实发生的工作，变成一张会生长的 RPG 角色卡。

DevQuest 观察 Agent 的回合、工具调用、代码行数、文件读写、待办清单、子代理和 workflow，将它们折算成经验、星币、装备、宝箱、成就、每日/每周/赛季 BOSS 与赛季通行证。它不修改 Agent 的循环，也不向对话写入任何内容；它只是坐在旁边，把已经发生的事讲成一段冒险。

## 一眼看到什么

- **等级与经验条**：成功工具调用 +6 XP，完成回合 +18 XP，写入文件额外 +4 XP，清空待办 +30 XP，workflow +70 XP，子代理 +30 XP。写代码的行数还会额外给经验。
- **像素战场**：总览与 BOSS 页顶部的像素小人斗兽场。你自己的像素冒险者对上每日/每周/赛季 BOSS，每一次真实的工具调用、完成回合、清空待办都会落下一刀：挥剑、暴击、飘伤害数字、BOSS 受击抖动，倒下时出现 VICTORY。想先看看动作，点「试斩」即可（不造成伤害）。
- **提升动画**：升级时弹出 LEVEL UP 庆祝层；战力上涨时角色卡与战场同时闪出「战力 +N」；经验条、BOSS 血条和赛季进度条都用平滑补间填充。
- **59 枚带稀有度的成就**：工具、文件、代码行数、宝箱、每日 BOSS、赛季 BOSS、连续天数、等级、装备收集、段位与收藏。解锁成就同时积累**成就点**（普通 1 / 稀有 2 / 史诗 3 / 传说 5 / 神话 8 / 红装 12），45 点可在成就页兑换一件红装。
- **巅峰等级**：等级上限 60；满级后每 20,000 经验获得一颗**巅峰之星**，每颗奖励星币（400、500、600…），1 / 3 / 5 / 10 星分别解锁「巅峰 / 超凡 / 无尽 / 永恒巅峰」称号；满级后经验条自动切换成「距下一颗星」。
- **装备系统**：武器、护甲、护符、头像框四个槽位，66 件装备（普通 / 稀有 / 史诗 / 传说 / 神话 / **红装**六阶）。装备有战力，战力会放大对 BOSS 的伤害。
- **强化系统**：武器 / 护甲 / 护符可强化 **+100**，每级 +2% 战力，费用随等级平方增长（80 → 42,254 星币）。
- **进阶系统**：在强化之上再加 **5 阶进阶**，每阶 +25% 战力；成功率 90% / 75% / 60% / 45% / 30%，失败也要付出星币。
- **常规战线**：一条无限关卡线，每次行动都会削当前关 BOSS 的血；血量每关 ×1.25（500 → 625 → 781…），战力不够就会卡住。通关给星币和经验，每 5 关额外一个星辉箱。
- **红装（赛季套）**：每个赛季 4 件（武器 / 护甲 / 护符 / 头像框），只在**赛季 BOSS 击杀**和**成就点兑换**两条路上产出，商店与宝箱都开不出来。
- **赛季 BOSS 专属武器**：6 个赛季 BOSS 各有一把签名武器（王权之刃 / 潮汐长枪 / 预言法杖 / 熵灭巨刃 / 镜像双刃 / 虚空之牙，战力 136–146），只有讨伐对应 BOSS 才会掉落，每次赛季击杀会同时掉一件红装和（若未拥有）该 BOSS 的签名武器。
- **工坊宝箱**：每写 **200 行代码**铸造一个宝箱。宝箱按累计行数升级为木箱、铁箱、金箱、星辉箱，可开出装备、星币和经验。
- **每日 BOSS / 每周 BOSS / 赛季 BOSS**：三条战线共享行动伤害；每日 9 种、每周 9 种、赛季 6 种怪轮换，每天 / 每周一 / 每 28 天自动更换。
- **怪物图鉴**：BOSS 页列出三条战线的全部 24 种怪，当前正在打的那只高亮，讨伐过的打勾并计次；旧存档会从当前战线和活动记录里补记。
- **赛季通行证**：每个赛季 15 个阶段、7 个段位（青铜→神话），靠声望往上爬；奖励含成堆宝箱、头像框，以及只走通行证才拿得到的**极光套装**与**泰坦套装**（泰坦切片、星织战衣、奇点之眼、泰坦框）。赛季结束自动更新，保留永久等级与装备。
- **头像框**：点装备页的四个槽位任意一个即可展开该槽位的全部装备，头像框以迷你徽章实时预览，点一下就换上；角色卡上的头像框名称、等级徽章、输入框 HUD 与像素战场会同时更新。
- **像素装备卡**：装备页左侧是穿着当前装备的像素小人，右侧四个槽位自带装备图标，点开就是带像素图标的候选装备——短刃、长枪、扳手、巨刃、箭矢、外套、胸甲、宝石、骰子、透镜、王冠，共 11 种像素造型，按稀有度换配色；装备库里也是同一套图标。
- **立绘头像**：人物卡用的是插件自带的插画立绘（`assets/hero.webp`，384×384，由 Host 的 `?asset=hero` 路由提供），装备页、战场、右下角挂件三处共用；图片加载失败时自动回退到下面的像素小人。
- **像素小人（备用）**：由**参数化渲染器**生成——骨架（头身比、肩宽、腰宽、腿长）固定，装备只给参数：护甲选剪影（合身外套 / 宽肩重甲 / 垂坠长袍）和配色，武器选形状与长度（匕首 / 长枪 / 扳手 / 巨刃 / 弓），护符是胸口一颗发光宝石；之后自动描边和明暗。
- **可拖动的 HUD**：右下角是一个角色挂件——像素小人（穿着当前装备）、头像框、等级徽章和经验条；悬停展开姓名、星币、连续天数、宝箱与委托进度，点一下打开完整面板，按住可以拖到别处，双击 `⠿` 归位。
- **商店**：称号、装备、头像框，另外可以直接用星币兑换木箱 / 铁箱 / 金箱 / 星辉箱；神话阶装备只在商店出售，是后期最大的星币去处。
- **每日委托与每周试炼**：按日期确定性轮换，进度由真实事件流推进。
- **每日命运抽奖**：每天一次，星币、经验或限定称号。
- **Agent 编队**：把参与过冒险的会话收进一张小队名单，子代理单独标记。
- **编年史**：由 Session 事件生成的时间线，不需要手写日志。

## 入口

- 左侧栏的 **DevQuest** 图标进入完整页面。
- 对话输入框下方有一条轻量 HUD：等级、经验、星币、连续天数、宝箱与可领取提示。点它也能进入完整页面。
- 页面页签：总览 / 委托 / 装备 / BOSS / 成就 / 商店 / 编年史。
- 所有 UI 跟随当前主题与语言；提供中文和英文文案。

## 事件如何变成进度

| 事件 | 进度 |
| --- | --- |
| `tool/result` 成功 | +6 XP、工具计数、相应分类计数、BOSS 伤害 |
| `write` / `edit` / `apply_patch` | 额外 +4 XP、文件写入计数、按新增非空行数累计代码行与宝箱进度 |
| `todo_write` 全部完成 | +30 XP、清单计数、BOSS 伤害 |
| `turn/end` completed | +18 XP、回合计数、BOSS 伤害 |
| `workflow/end` completed | +70 XP、workflow 计数 |
| `subagent/end` completed | +30 XP、子代理计数 |
| BOSS 归零 | 额外经验，并解锁对应成就 |

失败的工具调用不会给经验，但会计入「受挫次数」；之后的成功会累计「逆境翻盘」。

「清单归零」按清单内容去重：同一份清单反复提交只算一次，但换了一份新清单（或中间出现过未完成项）就重新计数——以前用的是一个布尔锁，全勾过一次之后永远不再计数，这正是它一直卡在 1/2 的原因。

## 装备与宝箱规则

- 武器 / 护甲 / 护符提供战力，也会改变像素小人的造型；头像框是纯外观，但会改变等级徽章、HUD、角色卡与战场里的小徽章。
- 战力公式：`实际 BOSS 伤害 = 基础伤害 × (1 + 战力 / 220)`。
- 每 200 行新增代码获得 1 个宝箱，累计行数决定箱子品质。
- 木箱、铁箱、金箱、星辉箱的装备概率和奖励逐级提高。
- 重复装备会自动转化为星币。
- 部分装备只能从每周 BOSS、赛季 BOSS、赛季通行证获得；极光套装标了 `chest: false`，开箱永远开不到，只能走通行证。

## 赛季规则

- 一个赛季 28 天，通行证 15 个阶段（250 → 37500 声望），每个阶段给经验、星币和成堆星辉箱，中后段是极光与泰坦套装。
- 段位只按声望算：青铜 0 / 白银 1500 / 黄金 4000 / 铂金 7000 / 星辉 11000 / 传说 16000 / 神话 24000，纯展示，不会卡领取。
- 声望来自每次真实行动造成的伤害；赛季结束时只重置声望、段位与通行证，等级、装备、成就都保留。

## BOSS 规则

- **每日悬赏**：每天 00:00 刷新，血量较低，讨伐后给经验、星币和铁箱。
- **每周灾厄**：每周一 00:00 刷新，讨伐后给经验、星币、金箱、灾厄征服框与灾厄断罪者。
- **赛季主宰**：每 28 天随赛季刷新，讨伐后给经验、星币、星辉箱、赛季冠军框、赛季荣耀战袍和称号。
- 三条战线的伤害同时结算；赛季声望只累计一次，用来推进赛季通行证。

## 数据与隐私

- 状态保存在 `D:\SC\devquest\data\state.json`，随插件目录一起移动；由 Host 本地读写，不联网、不上传。
- 只保存聚合计数和最近事件摘要，不保存完整的工具参数、对话文本或文件内容；工具摘要只记录工具名和文件基名，代码统计只保存行数。
- 每个 Session 用游标去重，重启后不会重复结算已经处理过的 Session 事件。
- Host 只在回环地址上注册 `/devquest/api`；页面同源读取。它不提供任何文件读取、命令执行或 Agent 控制能力。

## 安装

在 DSH 的插件管理器中以本地目录安装本文件夹：

```text
安装目标：D:\SC\devquest
```

安装后 Host 会加载事件投影与 API，浏览器会即时注册左侧栏图标、主面板和输入框 HUD。重新加载页面会重新连接已有状态，但不会清空进度。

若要清空进度，在 DSH 关闭时删除 `D:\SC\devquest\data\state.json` 即可。

## 分享给别人

插件本体只有 8 个文件（`index.js`、`client.js`、`cordis.patch.yml`、`locale/*.json`、`icon.svg`、`package.json`、`README.md`），不依赖任何第三方库，`data/`（你的存档）不会被打包。

### 方式一：发压缩包（最简单）

```powershell
cd D:\SC\devquest
npm pack
```

得到 `local-dsh-devquest-<版本>.tgz`（约 120 KB）。对方把这个文件发回来，解压后得到 `package/` 目录，然后在自己的 DSH 里让你（Agent）执行：

```text
用 plugin_manager 的 install_bundle，target 指向解压出来的 package 目录
```

### 方式二：发整个文件夹

直接把 `D:\SC\devquest` 压缩发给对方（**删掉 `data/` 再发**，否则会把你的存档一起送出去）。对方同样用 `install_bundle` 指向该目录。

### 方式三：Git 仓库 / npm

本仓库：<https://github.com/Yanchha/->

对方可以直接：

```powershell
dsh plugin --profile desktop add github:Yanchha/-
```

或在 `plugin_manager` 的 `install_bundle` 里填 `github:Yanchha/-`。若想公开发布到 npm，需要先把包名从 `@local/dsh-devquest` 改成你自己的 scope（例如 `@yourname/dsh-devquest`），再 `npm publish`，之后别人 `install_bundle "@yourname/dsh-devquest"` 即可。

### 对方安装后会发生什么

1. Host 侧开始收录事件、提供 `/devquest/api`；
2. 浏览器侧注册左侧栏图标、主面板和输入框 HUD（需要重新加载页面）；
3. 新用户从 1 级、80 星币、初始装备开始——进度存在**对方自己的** `data/state.json` 里，和你完全独立。

> 卸载：在插件管理器里移除该 bundle，或删除 profile 里对应的 patch 行即可；存档留在插件目录里，重装后继续。

## 开发说明

- 纯 JavaScript，无构建步骤，无第三方依赖。
- Host half 使用 `session/event`、`workflow/end`、`subagent/end`，只读观察。
- Client half 通过 `ctx.slots.inject` 注册 `main`、`sidebar.panellist` 和 `conversation.composer.dock`。
- 所有可见文案通过 `ctx.locale` 的 `devquest` 命名空间注册。
- 界面 chrome 只使用 `--dsw-alias-*` 主题令牌；固定颜色只出现在插件图标、SVG 纹章和像素精灵上（精灵是插画，需要稳定的调色板才能在明暗主题里都读得清）。
- 像素精灵写成「一行一个字符串」的网格（`PX_HERO` / `PX_IMP` / `PX_WRAITH` / `PX_SOVEREIGN`），每行长度必须一致，渲染时按横向同色连续段合并成 `<rect>`。
- 战斗与升级动画由 `diffSnapshots(prev, next)` 驱动：轮询通常返回同一份状态，只有 BOSS 伤害差、等级差、战力差或头像框变化才会触发动画，所以动画永远对应真实事件，不会自娱自乐。
- `prefers-reduced-motion` 下所有动画与补间都会关闭。

## 设计原则

1. 不改变 Agent 的行为，只解释已经发生的动作。
2. 奖励真实工作，不奖励刷屏：失败没有经验，重复的同一份待办不会重复计数。
3. 写代码、开宝箱、换装备、打 BOSS 形成闭环。
4. 赛季更新会重置赛季进度，但不会抹掉永久等级、装备和成就。
